# SXFTVision

Downloads of **SXFTVision**, real-time visual effects for video, images and live cameras on the Mac.

**Download and install:** https://updates.sxftkey.com/

Each version is a [release](../../releases) with a notarized zip. The app updates itself, so you only download it once.

Requires macOS 26 or later and a Mac with Apple silicon.

Feedback: Help > Send Feedback… in the app, or beta@sxftkey.com.

This repository holds downloads only; it has no source code.
